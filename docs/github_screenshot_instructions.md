# GitHub Screenshot Instructions

Use a fresh browser screenshot after all v2 files are uploaded and committed.

The screenshot should visibly show:

- repository owner and repository name;
- the **Public** visibility label;
- browser URL;
- latest commit message and recent commit date;
- top-level folders: `config`, `data`, `docs`, `notebooks`, `outputs`, `reports`, `scripts`, `src`, and `tests`;
- the revised README title and the beginning of the Current project status section.

Before capturing the screenshot:

1. Confirm that no token, API key, password, private email address, or local Windows path is visible.
2. Confirm that the README uses coal consumption, selected Indian states, Maharashtra and Gujarat as core states, and Odisha as conditional.
3. Confirm that the 2019–2026 range is called a data-search window and that 12–18 months is described as anticipated rather than confirmed.
4. Confirm that the v2 PDF is present under `reports/`.
5. Open the repository in a private/incognito window to verify public access.

Insert the screenshot into the report as an APA figure with the figure number in bold, the title in italics, and an explanatory note where needed.
